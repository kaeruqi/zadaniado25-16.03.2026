Pojęcie Znaczenie pojęcia
Co znaczy skrót ID? ID oznacza "identyfikator" (ang. identifier).
Jaki jest cel stosowania ID? Służy do jednoznacznego oznaczenia konkretnego elementu na stronie, aby nadać mu indywidualny styl.
Jakie jest znaczenie znaku #? Znak # służy do definiowania identyfikatora w CSS.
Jak następuje wywołanie ID (wraz z wytłumaczeniem) Wywołanie następuje poprzez zapis id="nazwa" w HTML, a w CSS używamy #nazwa. Dzięki temu przypisujemy styl do konkretnego elementu.
Uwagi na temat stosowania ID (3)konieczne wyliczenia
  • ID powinno być unikalne (tylko raz na stronie).
  • Nie należy powtarzać tego samego ID dla wielu elementów.
  • Jeśli element ma się powtarzać, lepiej użyć class.
